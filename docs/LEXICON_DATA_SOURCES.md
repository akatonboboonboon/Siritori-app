# プレイヤー入力辞書の出典とWikipediaの扱い

このアプリは、プレイヤーが入力した文字列を実行時に外部サイトへ送信しません。
入力された表記をローカルの辞書で完全一致検索し、名詞・読み・文字種の条件を満たす
場合だけ、しりとりの単語として受理します。

## 現在の判定元

- データ: SudachiDict-full 20260723
- 配布元: <https://pypi.org/project/SudachiDict-full/20260723/>
- Sudachi公式リポジトリ: <https://github.com/WorksApplications/Sudachi>
- 用途: 表記の完全一致、普通名詞／固有名詞の確認、ひらがな読みの取得

小さい`core`辞書から`full`辞書へ変更し、一般語だけでなく固有名詞を含む
より広い語彙を判定できるようにしました。辞書に収録されていても、部分一致、
複数語へ分割しただけの文字列、名詞以外、使用できない文字種は受理しません。

## Wikipedia日本語版によるカバレッジ測定

Wikipediaは現在の許可辞書ではなく、辞書がどの程度の見出し語を判定できるかを
測るベンチマークとしてだけ使用しました。

- 固定ダンプ:
  `jawiki-20260706-all-titles-in-ns0.gz`
- 配布元:
  <https://dumps.wikimedia.org/jawiki/20260706/>
- SHA-256:
  `371D68585163B851B99FFEF18E71545A44CC19A91439CD8C34B7DA436CA36743`
- 名前空間0のタイトル: 2,459,112件
- アプリの文字種・長さ条件に入るタイトル: 1,756,520件

同じ完全一致・名詞条件で比較した結果は次のとおりです。

| 辞書 | 受理できたWikipediaタイトル |
|---|---:|
| SudachiDict-core | 158,533件 |
| SudachiDict-full | 701,662件 |
| 増加 | 543,129件（+342.6%） |

`full`への変更で新たに受理できる代表例には、次があります。

- すみっコぐらし
- 鬼滅の刃
- 初音ミク
- ちいかわ
- スプラトゥーン
- アンパンマン
- クロミ

## Wikipedia検索を実行時の判定に使わない理由

Wikipediaに検索結果があることと、その入力がしりとり向けの単一名詞であることは
同じではありません。検索には部分一致、表記揺れ、リダイレクト、曖昧さ回避、
文章のような作品名も含まれます。通信障害、レート制限、応答時間、記事の更新により
同じ入力の判定が変わると、3秒手番や対戦の再現性にも影響します。

固定ダンプのうち、2〜30字のかなだけで読みを機械的に確定でき、
`full`の完全一致にない正規化済みタイトルは125,864語ありました。しかし、
Sudachiの追加解析で単一の既知名詞になったものは最大23,249語だけでした。
例えば「フォートナイト」「ヴァロラント」のような有用な候補がある一方で、
「かわいがる」のような動詞や、助詞を含む文章・複合作品名も混在します。
そのため、この125,864語を一括許可することはしません。

## 今後Wikipedia由来の語を追加する場合

追加語は実行時検索ではなく、次の条件で開発時に生成したレビュー済みCSVとして
固定します。

1. 固定ダンプの日時とSHA-256を記録する。
2. 名前空間0の完全一致だけを候補にする。
3. リダイレクト、曖昧さ回避、一覧ページを除外する。
4. かな2〜30字で、読みを決定的に取得できる語に限る。
5. 単一の普通名詞または固有名詞であることを確認する。
6. 未知語はWikidataの完全一致ラベルと種類、または人のレビューで二重確認する。
7. 表記、読み、出典、確認方法を各行に保存し、自動テストを通す。

この方法なら、外部サービスの状態に対局を左右されず、誤採用をGit差分で確認して
修正できます。
